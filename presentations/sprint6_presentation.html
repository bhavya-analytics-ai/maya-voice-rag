Why We Had To Fix Everything First

Sprint 5 gave generic answers

The Failure

Ask MAYA: "How do I install the Nyren?"

"Please refer to the installation instructions that come with your product."
Root Cause 1

Nyren PDFs are image-based scans. PyMuPDF extracted 0 text. ChromaDB had empty chunks — no data to answer from.

Root Cause 2

vectorstore.get() returns chunks in random insertion order. Chunk 0 was the cover page, not the installation steps.

The Fix

Same question after Sprint 6:

"Step 1: Shut off the water supply valve. Step 2: Remove the toilet tank lid. Step 3..." ↑ Real steps from the 32-page installation manual
Fix 1 — Vision OCR

GPT-4o-mini converts every PDF page to PNG and extracts all text. Nyren went from 5 chunks to 162.

Fix 2 — Source Filter

PRODUCT_SOURCE_MAP + similarity_search with filter ranks chunks by relevance. Cover page never appears.

The Core Fix

PRODUCT_SOURCE_MAP — targeted retrieval

When a question mentions a product + technical keyword, skip generic search. Go straight to that product's actual source document:

# Map: product keyword → source files PRODUCT_SOURCE_MAP = { "nyren": ["nyren-instalacion.pdf", "nyren-ficha-tecnica.pdf"], "aluvia": ["Sanitario_Aluvia_Plus.docx", "Aluvia-RD.pdf"], "cascade": ["Sanitario_Cascade.docx"], "cima": ["Sanitario_Cima.docx"], } # similarity_search WITH source filter ranked = _vectorstore.similarity_search( question, k=20, filter={"source": src} # ← ranked by relevance )
Why .get() was wrong

vectorstore.get() returns chunks in random insertion order. Chunk 0 = cover page. LLM had no real content — returned a generic placeholder answer every time.

Why filter works

similarity_search ranks chunks by cosine distance to the question. Installation steps rank #1 for "how do I install". The cover page doesn't appear.
