Why We Had To Fix Everything First
Sprint 5 gave generic answers
The Failure

Ask MAYA: "How do I install the Nyren?"

"Please refer to the installation instructions that come with your product."
Root Cause 1

Nyren PDFs are image scans. PyMuPDF extracted 0 text. ChromaDB had empty chunks.

Root Cause 2

vectorstore.get() returns chunks in random order. Chunk 0 was the cover page, not steps.

The Fix

Same question after Sprint 6:

"Step 1: Shut off the water supply valve. Step 2: Remove the tank lid..."↑ Real steps from the 32-page installation manual
Fix 1 — Vision OCR

GPT-4o-mini converts every PDF page to PNG, extracts all text. 5 chunks → 162.

Fix 2 — Source Filter

PRODUCT_SOURCE_MAP + similarity_search with filter ranks by relevance, not random order.

The Core Fix
PRODUCT_SOURCE_MAP — targeted retrieval

When a question mentions a product + technical keyword, skip generic search. Go straight to that product's source document:

# Map: product keyword → source files PRODUCT_SOURCE_MAP = { "nyren": ["nyren-instalacion.pdf", "nyren-ficha-tecnica.pdf"], "aluvia": ["Sanitario_Aluvia_Plus.docx"], "cascade": ["Sanitario_Cascade.docx"], "cima": ["Sanitario_Cima.docx"], } # similarity_search WITH source filter ranked = vs.similarity_search( question, k=20, filter={"source": src} # ranked by relevance )
Why .get() was wrong

Returns chunks in random insertion order. Chunk 0 = cover page. LLM had no real content — returned a generic placeholder every time.

Why filter works

similarity_search ranks by cosine distance to the question. Installation steps rank #1 for "how do I install". Cover page never appears.
